# Kortex — Personal AI Workspace & MCP Bridge

> **Персональное рабочее AI-пространство и мост к подключенным приложениям через Model Context Protocol (MCP)**

Kortex — это автономный личный AI-ассистент для продуктивности, учебы, управления задачами, заметками и внешними сервисами. Проект спроектирован для одного владельца и ориентирован на безопасность, контроль данных и удобство голосового и текстового взаимодействия.

---

## 🌟 Ключевые возможности

1. **AI-ассистент (Главный экран)**:
   - Общение на естественном русском языке.
   - Потоковый вывод ответов (SSE streaming).
   - Поддержка контекста выбранного проекта.
   - Подключение долговременной памяти к системному промпту.
   - Честное состояние при отсутствии настроенного провайдера (никаких фальшивых ответов).

2. **Голосовой режим (Jarvis Mode)**:
   - Быстрый запуск голосового управления.
   - Распознавание русской речи в реальном времени через браузерный Web Speech API (`ru-RU`).
   - Синтез речи для голосовых ответов ассистента с возможностью паузы и отключения звука.

3. **Мост Model Context Protocol (MCP Bridge)**:
   - Полноценная поддержка официального SDK `@modelcontextprotocol/sdk`.
   - Серверный шлюз (`server/src/mcp/gateway.js`) для подключения внешних MCP-серверов по транспорту Stdio (Filesystem, GitHub, Notion, Google Workspace и др.).
   - Встроенный сервер инструментов `kortex-core` (получение времени, поиск по задачам, создание задач, сохранение в память).
   - Инструмент для интерактивного тестирования вызовов MCP прямо из интерфейса.

4. **Контроль действий (Human-In-The-Loop)**:
   - Безопасное разделение операций: операции чтения выполняются автоматически, а действия с изменением или записью данных (создание задач, изменение файлов, отправка писем) требуют явного подтверждения владельца в интерфейсе.

5. **Проекты и Задачи**:
   - Рабочие области проектов с заметками и контекстом для языковой модели.
   - Личный планировщик задач с приоритетами (Высокий, Средний, Низкий), дедлайнами и фильтрами.

6. **Долговременная память (Personal Memory)**:
   - Управление фактами, правилами и предпочтениями.
   - Категории: Предпочтения, Контекст, Факты, Цели.
   - Возможность включения/выключения памяти глобально или для каждой отдельной записи.

7. **Продвинутая автоматизация (Сценарии)**:
   - Сохранен визуальный редактор сценариев и библиотека шаблонов в качестве расширенной функции (`/workflows`).

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
# Установка зависимостей клиента
cd my-landing && npm install

# Установка зависимостей сервера и MCP SDK
cd ../server && npm install
cd ..
```

### 2. Запуск в режиме разработки

В первом терминале запустите сервер бэкенда и MCP мост:
```bash
npm run dev:server
```
*Сервер запустится на `http://localhost:3001`.*

Во втором терминале запустите клиентский интерфейс:
```bash
npm run dev:client
```
*Интерфейс откроется по адресу `http://localhost:5173`.*

## ⚙️ Настройка AI-провайдера

Настроить модель можно двумя способами:

### Вариант А: Через интерфейс
Перейдите в раздел **Настройки** (`/settings`):
1. Выберите провайдера: **OpenAI**, **OpenRouter**, **Ollama (локально)** или **Anthropic**.
2. Укажите API-ключ (сохраняется строго на сервере в `server/data/secrets.json`, не передается в браузер).
3. Нажмите **Сохранить изменения**.

### Вариант Б: Через переменные окружения
Создайте файл `server/.env` (на основе `server/.env.example`):
```env
PORT=3001
AI_PROVIDER=openai
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
AI_API_KEY=ваш_ключ_api
```

Для использования бесплатной локальной модели через **Ollama**:
```env
AI_PROVIDER=ollama
AI_BASE_URL=http://localhost:11434/v1
AI_MODEL=llama3.2
AI_API_KEY=
```

## 🔌 Подключение первого MCP-сервера

Чтобы подключить локальный MCP сервер файловой системы:

1. Перейдите в раздел **Подключения** (`/connections`).
2. Нажмите **Добавить MCP сервер**.
3. Заполните поля:
   - **Название**: `Локальные заметки`
   - **Команда**: `npx`
   - **Аргументы**: `-y @modelcontextprotocol/server-filesystem C:\Users\user\Desktop\notes`
4. Нажмите **Подключить сервер**.
5. Kortex запустит MCP-сервер по протоколу Stdio, считает манифест инструментов и сделает их доступными для вызова AI-ассистентом!

## 🔒 Безопасность

- **Секреты**: API-ключи провайдеров хранятся исключительно на сервере и не включаются в клиентский бандл.
- **Мастер-токен**: в production-режиме можно задать `OWNER_TOKEN` в `server/.env` для защиты всех API-эндпоинтов персональным паролем.
- **Подтверждение действий**: чувствительные функции изменения данных требуют нажатия кнопки «Подтвердить и выполнить».
