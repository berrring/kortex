# Kortex.ai — Платформа автоматизации рабочих сценариев

> **Меньше рутины. Больше времени на важное.**
> Современный и понятный интерфейс для управления сценариями автоматизации повседневных бизнес-процессов.

---

## 🚀 О проекте

**Kortex.ai** — это веб-приложение для малого бизнеса, предпринимателей и команд, позволяющее создавать, визуально настраивать и контролировать цепочки действий без сложного программного кода.

### Основные разделы:
- **Маркетинговый сайт**: Главная (`/`), Возможности (`/features`), Как это работает (`/how-it-works`), Тарифы (`/pricing`), Вопросы и ответы (`/faq`), Контакты (`/contact`).
- **Авторизация**: Вход (`/login`), Регистрация (`/signup`), Восстановление доступа (`/forgot-password`).
- **Рабочая область**:
  - **Главная (`/app`)**: ключевые метрики и чек-лист первых шагов.
  - **Сценарии (`/app/workflows`)**: полный список сценариев, фильтрация по категориям, создание и удаление.
  - **Редактор (`/app/workflows/:id`)**: визуальный пошаговый конструктор (события, действия, условия, задержки).
  - **Шаблоны (`/app/templates`)**: готовые сценарии для продаж, поддержки, отчетов и уведомлений.
  - **Подключения (`/app/integrations`)**: каталог сервисов (Telegram, Google Таблицы, Почта, CRM, Notion).
  - **История (`/app/activity`)**: журнал выполненных операций и тестовых запусков.
  - **Настройки (`/app/settings`)**: управление профилем, экспорт и импорт сценариев в JSON, выбор светлой или темной темы.

## 🛠 Технологический стек

- **React 19** + **Vite**
- **Tailwind CSS v4**
- **React Router DOM v7**
- **Lucide React** (иконки)
- **Локальное хранение**: `localStorage` (полная автономность без внешних серверов на этапе прототипа)

---

## 📦 Быстрый старт

### 1. Установка зависимостей
```bash
npm install --prefix my-landing
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:5173`.

### 3. Сборка для production
```bash
npm run build
```
